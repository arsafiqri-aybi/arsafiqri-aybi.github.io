# Visual

## Intent

A complete redesign authorized on 3 November 2026. Existing pages supply factual content and approved evidence, not visual direction. The previous spatial navigation, color system, layouts, CSS cascade and carousel behavior are replaced. Earlier designs remain in Git history.

The new experience presents Arsafiqri as a thoughtful strategist and hands-on digital builder. Warm paper, dark ink and cobalt create an editorial identity; large sans-serif headings and occasional serif emphasis balance clarity with personality. Original project media provides substance. The sequence is introduction → selected work → independent explorations → background → approach → conversation.

## Visual coverage

Histourgia Website Visual's six groups and eighteen divisions informed the design and review. These are areas of expertise for one AI, not running sub-agents. The inventory is a reference map; a portfolio does not need unrelated forms, shopping interfaces, 3D scenes or application states merely to demonstrate coverage.

| Division | Applied decisions and review focus |
| --- | --- |
| Spatial & Composition | Shared container edges; asymmetric hero; a full-width first project followed by two related cards; deliberate light, dark and cobalt section changes. |
| Layout Mechanics | Grid and normal document flow; no absolute page positioning, scroll interception or hidden chapter content; sticky header and case navigation have explicit bounds. |
| Micro-Spatial Precision | Related labels and text remain grouped; button and icon geometry use consistent clearances; captions align with media; optical adjustments keep the brand glyph balanced. |
| Typography | Locally bundled DM Sans paired with system Georgia; controlled reading measures; fluid display sizes; sensible paragraph leading; long titles wrap without covering adjacent content. |
| Color & Light | Semantic paper, ink, secondary text, rule and interaction tokens; cobalt identifies actions; project media retains its authentic colors; selection is also indicated by a line. |
| Shape, Surface & Depth | An arched portrait is the main distinctive contour; quiet rectangular project frames; consistent small radii; restrained contact shadows on artwork. |
| Visual Assets & Graphics | Approved portrait in Home; byte-verified project evidence; aspect ratios and dimensions reserve space; full images stay intact; SVG arrows share one stroke language. |
| Human Visual Perception | One main focal statement; clear separation of identity, evidence and interpretation; consistent grouping; no simultaneous competing motion or decorative graphs. |
| Interface Components | A real masthead, native navigation, project entries, article sections, facts, tables, quotations, sources disclosure, media dialog and coherent footer. |
| Component States | Hover, keyboard focus, current section, pressed actions, open/closed sources, dialog open/closed and image-failure presentation are explicit. |
| Interaction Signifiers | Visible link labels, directional arrows and sufficiently sized controls; image enlargement also remains an ordinary full-image destination. |
| Motion & Transitions | Brief entrance and pointer feedback; native anchor movement; interruptible preference handling; reduced motion removes animation without altering layout. |
| Responsive & Adaptive Visual | Desktop two-column composition becomes mobile reading flow; navigation remains directly visible; project cards stack; tables scroll within their own boundary. |
| Visual Accessibility | Strong text contrast; meaningful headings and alt text; skip target; focus moves to the destination heading; native dialog semantics; forced-color and print rules. |
| Rendering & Pixel Fidelity | Local fonts and explicit media geometry reduce late shifts; no external UI dependency; no persistent hidden/transparent content; image scaling inspected in the browser. |
| Content & Edge Cases | Reviewed long case text, historical metrics, mixed English/Indonesian quotation, missing images, long project names and narrow widths have deliberate treatment. |
| Contextual Visual Specialization | A portfolio foregrounds real work and personal perspective; long-form cases use a separate reading rhythm without inheriting application-style navigation. |
| Visual Quality Assurance | Generated-output checks, content/provenance tests, numeric contrast checks and actual Chromium observations are kept distinct from untested device/browser claims. |

## Verification record

- The renderer reproduces all ten generated files; it validates the public selection, external URL schemes and reviewed media hashes.
- The updated automated suite passes 111 checks. Assertions tied to the removed arc/carousel design were replaced with checks for the new published experience; reusable publication, media and planning tests remain.
- Chromium desktop Home was visually inspected with its complete title, portrait, navigation and original imagery. Mobile Home and Work were inspected at a 390px iframe width. waai.id was checked at 320, 390, 768, 1024 and 1363px iframe widths: document widths matched their scroll widths at each size, with all four header navigation targets measuring 44px high.
- Browser observations confirmed Work navigation updates the location and active indicator, moves focus to the Work heading and positions that heading below the sticky masthead.
- The first visual review corrected combined anchor offsets, screenshot cropping and an About line-break issue. Important content remains static HTML; no private source data or new contact claims were introduced.

- Tari Cookies desktop reading, the original owner response and image enlargement were visually inspected. Opening the native dialog focused Close; Escape closed it and restored focus to the original image link.
- The dense tables stay inside their own horizontal boundary; two-column tables adapt to the reading width on small screens. Five-column comparison tables preserve room for their values.
- Independent project pages retain their documented system components and original source links in a new reading layout, including the existing `technical` fragment.
- A text-based 1200 × 630 PNG sharing image and a matching SVG source replace the former visual identity without reusing the portrait outside its approved scope.

- Without JavaScript, the Work link updated the fragment and placed the Work heading at 175px below the top of a 375px-wide document, clear of the 121px masthead; document and scroll widths matched.
- The image-failure state was exercised through the isolated QA surface; its description remained visible and the portrait frame retained its geometry.
- The Home tablet composition and the long Scale & Governor title were visually inspected. Header controls remained directly visible with no page-level horizontal overflow.

Remaining limits: Physical devices, Safari, Firefox, screen-reader behavior, forced-color rendering and browser text zoom require separate verification. There is no claim that every item in the visual inventory has been empirically tested.
