# Ars — Portofolio (arsafiqri-aybi.github.io)

Situs statis tanpa build, tanpa dependensi, tanpa layanan berbayar. Tampilkan lokal: `python3 -m http.server 8000`, lalu buka http://localhost:8000.

Berkas: index.html (isi), styles.css (token dan tata letak), app.js (penyaring lapisan, opsional), fonts.css (Manrope dan DM Sans tertanam, lisensi OFL disertakan).

Isi dirangkum dari README repositori publik pemilik. Status bukti tiap proyek disalin dari README masing-masing; ubah bersama README-nya bila statusnya berubah.

Publikasi: GitHub Pages dari cabang main, root repositori. Hapus berkas lama yang tidak ada di paket ini (work/, tools/, VERIFICATION.md) bila ingin bersih.
