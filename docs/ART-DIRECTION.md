# Ars — logic × feeling

One identity: cinematic editorial typography, restrained dark surfaces, copper geometry, and original project-specific visual studies. The hero names Ars and his focus immediately. No blocking intro, soundtrack, cursor replacement, scroll hijacking, or perpetual animation is needed.

| Role | Decision |
| --- | --- |
| Ground | Near-black `#141412`, muted rule `#3b3b35` |
| Copy | Warm white `#eeeae2`, muted `#aaa79e` |
| Accent | Copper `#e6a478` for focal typography and feedback |
| Capability | Sage `#bdc7ad`, dark forest text |
| Contact | Warm copper `#e2aa85`, dark brown text |
| Typography | Existing licensed self-hosted Manrope / DM Sans; system Georgia for italic editorial contrast |
| Composition | Dominant preview, narrow unboxed vertical selection, three visible choices with native local scrolling |
| Rhythm | Identity → selected work → capability → personal approach → contact |
| Case study | Original art → overview / role → need → decision → contribution → result / sources / limits |

On phones, the selected preview comes before the vertical list. No controls require hover. Without JavaScript all six original preview articles and case-study links remain in document order. The design is an authored hypothesis, not human research or a promise of an emotional response.
