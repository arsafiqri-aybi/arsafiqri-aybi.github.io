Skill & knowledge base

01 / KEBUTUHAN

Masalah yang ingin dijawab.

Website dapat terlihat menarik tetapi gagal menjelaskan tujuannya, sulit dipakai, atau terlalu berat. Keberhasilan build belum menunjukkan kualitas pengalaman yang sesungguhnya.

02 / KEPUTUSAN

Arah yang dipilih.

Menggunakan alur tujuan → hambatan → hipotesis desain → perilaku → verifikasi. Prinsip persepsi digunakan secara kontekstual, lalu diwujudkan dalam komposisi, state, serta fallback yang dapat diuji.

03 / KONTRIBUSI

Bagian yang kubangun.

  • Menyatukan UX, identitas visual, frontend, aksesibilitas, dan performa.
  • Menyusun referensi domain dan gerbang penerimaan berbasis bukti.
  • Menghubungkannya dengan Portofolio Web untuk penerapan frontend statis.
04 / HASIL

Yang bisa diperiksa.

Runtime skill dan referensi tersedia di repositori. Portofolio Web melengkapinya dengan 32 modul, playbook, contoh, serta matriks pemeriksaan untuk website portfolio.
