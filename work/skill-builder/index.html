Context & Contribution

Why this work exists.

Long instructions do not necessarily make a reliable skill. Triggers, boundaries, sources of truth, failure handling, and output format need to be inspectable.

Skill Builder turns user needs into capability packages with an explicit purpose and boundaries. Runtime instructions stay concise; deeper references are loaded when needed.

Decisions & Process

Defining boundaries before execution.

Real needs become reusable capabilities.

Separate runtime instructions, references, knowledge, tooling, and evaluation. Make targeted changes to existing skills while preserving their identity and unrelated behavior.

Outcome & Limitations

What the evidence can support.

The repository provides initialization, metadata, validation, audit, and regression-test scripts. Skill packages can be inspected before use in their target environment.
